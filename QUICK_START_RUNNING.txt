TROUBLESHOOTING:

Port 5000 already in use?
  → Use: PORT=8000 python run.py

"Module not found" error?
  → Run: pip install -r AdminLoginPanel/requirements.txt

Templates not found?
  → Ensure you run from project root directory

Database locked?
  → Delete project_management.db and restart
